## 写作模板

### 结构
1. **Hook** (50 字): 痛点或惊讶数据
2. **Answer First** (100 字): 直接回答标题问题
3. **Body** (1200-2000 字): 分节展开，每节一个小标题
4. **Table/Chart**: 至少 1 个数据表格或对比表
5. **FAQ**: 3-5 个常见问题
6. **CTA**: 相关工具页 + 产品页 + 询盘表单

### SEO 检查清单
- [ ] 标题含目标关键词
- [ ] URL slug 含目标关键词
- [ ] Meta description 150 字以内
- [ ] H1 唯一，H2-H3 含相关关键词
- [ ] 至少 2 个内部链接（工具/产品页）
- [ ] 至少 1 个外部权威链接（ASTM/ISO/Wikipedia）
- [ ] 图片 alt 文本
- [ ] Schema markup (FAQPage)

### 语调
- 买家视角：解决采购问题，不是卖产品
- 数据驱动：引用标准、测试数据、行业统计
- 诚实透明：承认中国供应链风险，教买家如何验证
